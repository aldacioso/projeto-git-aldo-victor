# Projeto Dev-Front II

Página web inicial desenvolvida com HTML, CSS e JavaScript puro, como parte da disciplina de Desenvolvimento Front-End II.

## Sobre o projeto

A página exibe uma barra de navegação e um cabeçalho de boas-vindas. Ao carregar, os elementos aparecem com uma animação suave de *fade-in* e deslocamento vertical, em sequência.

### Funcionalidades

- **Barra de navegação** com os itens: Página Inicial, Sobre a página, Sobre a empresa e Contato, alinhados à direita.
- **Cabeçalho** centralizado com a mensagem de boas-vindas.
- **Animação de entrada**: `nav` e `header` surgem com transição de opacidade e movimento (0,8s), com atraso de 250ms entre um e outro.

## Tecnologias

- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla)

## Como executar

1. Clone o repositório:

   ```bash
   git clone <url-do-repositorio>
   ```

2. Abra o arquivo `index.html` no navegador (ou use uma extensão como o *Live Server* do VS Code).

Não é necessário instalar dependências.
